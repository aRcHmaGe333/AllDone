# External Positioning

Status: active

Purpose
-------
This document keeps public claims aligned with the evidence that currently exists.

## Current position

AllDone is public, documented and prototype-backed.

The repository contains a defined system, a narrow pilot model, container and wash specifications, planning economics and working backend flows for the main operator sequence.

The project is still pre-pilot. Live customer retention, route performance, wash cost, breakage, return behaviour and contribution data do not exist yet.

## Public description

For a general public or GitHub audience:

**AllDone is a closed-loop household supply system designed to replace routine shopping for recurring goods with reusable containers, scheduled delivery and return, washing and recirculation.**

Useful supporting facts:

- the system and pilot are documented publicly
- the repo contains working prototype code
- reusable-container and wash/return operating work is already defined
- physical performance and live economics still require a pilot

## Investor description

For early investor and strategic-partner conversations:

**AllDone has a coherent system design, a defined first pilot, planning economics and a working operator-flow prototype. Early funding would be used to turn those plans into measured operating evidence.**

The next proof stage should produce:

- real supplier and landed-cost data
- physical container and closure test results
- measured wash and return cost
- a real pilot site and recruited households
- route, retention, return and contribution data
- pilot-safe software and operator interfaces

## Pilot-partner description

For a building, wash partner, logistics partner or other party being asked to participate in live operation:

**AllDone is preparing a narrow 60-household pilot in one dense residential environment, with weekly service, a small staple range, reusable containers, deposit-backed returns and centralized washing.**

This description should be used only alongside the actual operating details that the partner needs: container sourcing, food categories, wash process, site access, responsibilities, compliance and software workflow.

## Stage language

Use **pre-pilot** for the current stage.

Use **pilot-ready** when the required physical supply path, wash and inspection process, operator software, pilot site and compliance pathway are materially in place.

Use measured claims only after the relevant pilot data exists.
