# Pilot

This is the part to read if the question is: **what would it take to run AllDone for real?**

Start with:

- [Pilot brief](../PILOT_BRIEF.md) — the short version.
- [Pilot model and assumptions](../PILOT_MODEL_AND_ASSUMPTIONS.md) — the actual working shape of the first test.
- [Pilot readiness gaps](../PILOT_READINESS_GAPS.md) — what still has to be solved before launch.
- [Pilot unit economics](../PILOT_UNIT_ECONOMICS.md) — the current numbers and assumptions.
- [Operations MVP scope](../OPERATIONS_MVP_SCOPE.md) — what the operating system actually needs to cover.
- [Regulatory and food-safety checklist](../REGULATORY_AND_FOOD_SAFETY_CHECKLIST.md) — the boring things that become extremely non-boring once somebody is eating what you delivered.

The first pilot is meant to be deliberately narrow. One dense area, a small SKU set, recurring use, containers coming back, and enough repetition to find out whether the loop is genuinely better instead of merely sounding better on paper.
